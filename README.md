# Telegram Stories Collage

Небольшой набор Python-скриптов для публикации большой фотографии в виде мозаики\коллажа из Telegram Stories.

Изображение нарезается на несколько частей, которые затем загружаются в истории Telegram в нужном порядке. После успешной загрузки скрипт может автоматически открыть истории для всех пользователей.

Проект рассчитан на **Telegram для iPhone**, где истории отображаются в виде сетки на странице профиля.

## Возможности

- Нарезка изображения на мозаику с тремя колонками.
- Настройка количества строк через `config.toml`.
- Расчёт рекомендуемого количества строк по пропорциям исходного изображения.
- Создание изображений в формате Telegram Stories.
- Поддержка чёрного и прозрачного фона.
- Загрузка историй через Telegram API.
- Первичная публикация историй только для владельца аккаунта.
- Автоматическое открытие всех успешно загруженных историй для всех пользователей.
- Возможность закрепить истории в профиле.
- Задержка между загрузками для снижения нагрузки на Telegram API.
- Обработка `FloodWaitError` при изменении приватности историй.
- Сохранение идентификаторов загруженных историй в файл.

## Как это работает

Проект состоит из двух скриптов:

### `create_stories.py`

Подготавливает изображение:

1. Загружает исходную фотографию.
2. Рассчитывает размеры мозаики.
3. Делит изображение на части.
4. Размещает каждую часть в формате Telegram Story.
5. Сохраняет готовые изображения в отдельную папку.

### `upload_stories.py`

Загружает подготовленные изображения в Telegram:

1. Проверяет доступное количество историй.
2. Загружает изображения в обратном порядке.
3. Сначала делает истории приватными.
4. После успешной загрузки всех частей открывает их для всех пользователей.
5. Сохраняет соответствие между именами файлов и `story_id`.

## Требования

- Python 3.11 или новее
- Telegram-аккаунт (желательно с Premium'ом воизбежании проблем)
- API ID и API hash Telegram-приложения
- Установленные зависимости из `requirements.txt`

`tomllib` входит в стандартную библиотеку Python начиная с версии 3.11.
